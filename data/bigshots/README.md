# Bigshot source files

Place historical public-domain PGNs here only after recording their source URL in `config/bigshots.json`. Ingestion rebuilds the sample PGN mainline and drops comments, variations, NAGs, and source annotations.

Corpus files and matcher dry-run output are ignored by Git because they can be large or contain private game data. Lichess broadcast inputs must be configured with the required `Game data via Lichess broadcasts, CC BY-SA 4.0` attribution. The question of whether share-alike applies to derived vectors remains open for IP counsel before commercial release.
